Publication · PostFlow

Ce navigateur est un profil : la session Facebook ouverte ici est le compte qui publiera. Renseigne le profil correspondant dans l'API data-fb-posting, puis pilote la boucle depuis l'icone de l'extension.

Appairage

Dans l'admin : Pilotage → la ligne de ce profil → Appairer. Colle le code ici : ce navigateur apprend l'adresse du serveur, sa cle et lequel des profils il est. Rien d'autre a saisir.

Sans code : une extension preconfiguree (npm run pack:preset) detecte seule son profil NSTBrowser et s'appaire au demarrage.

Pilotage depuis l'admin

L'adresse de l'API, la cle et l'identifiant de profil ne sont jamais pousses par le serveur : ce sont eux qui font que ce navigateur est bien celui-la.
